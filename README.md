# Chill with You 番茄钟悬浮窗 / Pomodoro Overlay

在桌面置顶显示《放松时光：与你共享 Lo-Fi 故事》的番茄钟，并与游戏内的计时状态同步。

游戏版本：**1.17.3（Steam Build 25498460）** · Windows

### 安装与使用

1. 下载 [ChillTimerOverlay.zip](https://github.com/lsdlBlueDragon/chill-with-you-timer-overlay/raw/refs/heads/main/ChillTimerOverlay.zip)。
2. 在 Steam 游戏库中右键游戏，选择「管理 → 浏览本地文件」。
3. 将压缩包内的所有文件解压到游戏目录，也就是 `Chill With You.exe` 所在的文件夹，然后启动游戏。
4. 表盘上的 ▶、Ⅱ、■ 分别用于开始或继续、暂停和结束番茄钟；拖动表盘可以移动位置。
5. 右键表盘可调整透明度或关闭悬浮窗，也可以用鼠标滚轮调整透明度。关闭后重新启动游戏即可再次显示。

---

An always-on-top desktop Pomodoro timer synchronized with **Chill with You: Lo-Fi Story**.

Game version: **1.17.3 (Steam Build 25498460)** · Windows

### Installation and use

1. Download [ChillTimerOverlay.zip](https://github.com/lsdlBlueDragon/chill-with-you-timer-overlay/raw/refs/heads/main/ChillTimerOverlay.zip).
2. In your Steam library, right-click the game and select **Manage → Browse local files**.
3. Extract all files from the ZIP into the game folder containing `Chill With You.exe`, then launch the game.
4. Use ▶, Ⅱ, and ■ on the dial to start or resume, pause, and end the timer. Drag the dial to move it.
5. Right-click the dial to adjust opacity or close the overlay. You can also adjust opacity with the mouse wheel. Restart the game to reopen the overlay.
